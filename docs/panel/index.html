Dodawaj, edytuj i usuwaj artykuły bloga. Po zapisaniu strona przebuduje się sama w ciągu 2–3 minut (lista po 12 na stronę i sitemap aktualizują się automatycznie).

Połącz z GitHubem

Panel zapisuje artykuły w repozytorium strony. Potrzebuje do tego Twojego klucza dostępu (token). Klucz jest zapisywany tylko w tej przeglądarce i trafia wyłącznie do GitHuba.

Jak wygenerować klucz (jednorazowo, 2 minuty)
  1. Zaloguj się na GitHub i wejdź w Settings → Developer settings → Fine-grained tokens → Generate new token.
  2. Nazwa: panel-artykulow. Wygaśnięcie (Expiration): najdłuższe możliwe.
  3. Repository access: Only select repositories i wybierz kalendarz-tranzytow.
  4. Permissions → Repository permissions → Contents: Read and write. Pozostałe zostaw bez zmian.
  5. Kliknij Generate token i skopiuj klucz (pokaże się tylko raz). Wklej go powyżej.
